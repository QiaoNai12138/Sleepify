## ⚠️ 警告：标准电压移动版锐龙 5000 / 6000 / 7000

标准电压移动版锐龙 5000–7000 系列（H / HS / HX）存在低电压稳定性问题。**如果您的 CPU 属于这一范围，请谨慎使用本工具。**

## 工作原理

Sleepify 不执行真正的睡眠。它通过冻结进程、关闭非必要的设备与项目来模拟睡眠，让设备保持供电但处于空闲状态。

## 安装

### 免安装版

1. 解压压缩包。
2. 运行 `start.cmd`，脚本会检测您的设备并生成适配您设备的休眠方案。
3. 双击 `Sleepify.exe`。

### 安装器

安装器默认启用 `start.cmd`。安装完成后，直接双击 `Sleepify.exe` 即可。

## 卸载

双击安装目录中的 `uninstall.cmd`，脚本会恢复 Sleepify 运行所做出的一切更改。

随后您可以点击 **删除** 移除本工具，也可以手动删除安装目录。本工具的所有内容均保存在该目录内。

## 修复 / 重新配置

如果设备配置发生变化，或工具工作不正常，可以重新配置：

1. 运行 `uninstall.cmd`，让它恢复所有更改。
2. 结束时**不要点击「删除」**，关掉这个页面即可。
3. 再次运行 `start.cmd`，它会重新为您的设备进行配置。

## 环境要求

- Windows 10 (1903+) 或 Windows 11
- .NET Framework 4.8（系统自带）
- 管理员权限——脚本与程序会自动提权
- 二进制未签名，SmartScreen 会警告，选择「仍要运行」
